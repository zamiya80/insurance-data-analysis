# insurance-data-analysis

## 📌 Project Overview

This project analyses insurance customer data to identify purchasing patterns, customer trends, and opportunities for improving policy offerings and claims management.

The analysis focuses on understanding customer behaviour and policy trends using Python and Pandas.

## 🎯 Objective

To analyse insurance customer data to identify:

* Customer purchasing patterns
* Customer behaviour trends
* Policy trends
* Potential opportunities for improving policy offerings
* Potential opportunities for improving claims management

## 🛠️ Tools & Technologies

* Python
* Pandas
* Data Analysis
* Data Visualisation
* Jupyter Notebook

## 📊 Dataset

The analysis was conducted on insurance data covering **10,000+ customers**.

The dataset was explored to identify patterns in customer behaviour, policy purchasing and other relevant trends.

## 🔍 Analysis Process

### 1. Data Exploration

Explored the insurance dataset to understand customer and policy-related information.

### 2. Data Analysis

Used Python and Pandas to analyse the data and identify customer behaviour patterns and purchasing trends.

### 3. Data Visualisation

Created visualisations to help interpret customer and policy trends and make the findings easier to understand.

### 4. Insights & Opportunities

Interpreted the results to identify potential areas for targeted interventions and improvements to policy offerings.

## 📈 Key Result

The analysis identified actionable customer trends and potential opportunities to reduce claims costs by **up to 5% annually** through targeted interventions and enhanced policy offerings.

## 💡 Key Skills Demonstrated

* Data cleaning and exploration
* Data analysis with Pandas
* Customer behaviour analysis
* Pattern identification
* Data visualisation
* Business insight generation
* Interpretation of analytical results
